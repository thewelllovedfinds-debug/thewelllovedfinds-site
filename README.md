# thewelllovedfinds.com

UGC portfolio for The Well Loved Finds (Ali & Justin, South Florida). Static site served by GitHub Pages from the `main` branch.

- `index.html`, `styles.css`, `script.js`: the page, its styles (The Well Loved Finds design system) and the video / copy-email script.
- Work is grouped into rows (Pet, Home + outdoor, Kitchen + drinks, Couples + travel, Series); each card is an `<article class="card">` inside its row.
- `assets/`: web videos (`*-web.mp4`) and their cover images (`*-poster.jpg`), plus photos.

Updated weekly.
