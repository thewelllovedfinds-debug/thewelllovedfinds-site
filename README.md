# prettylivedin.com

UGC portfolio for Pretty Lived In (Ali & Justin, South Florida; formerly The Well Loved Finds). Static site served by GitHub Pages from the `main` branch.

- `index.html`, `styles.css`, `script.js`: the page, its styles (Pretty Lived In, Kit A: Fraunces, Montserrat, Caveat; logo in Sacramento + Instrument Serif) and the video / copy-email script.
- Work is grouped into rows (Pet, Home + outdoor, Kitchen + drinks, Couples + travel, Series); each card is an `<article class="card">` inside its row.
- `assets/`: web videos (`*-web.mp4`) and their cover images (`*-poster.jpg`), plus photos.

Updated weekly.
