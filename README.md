# thewelllovedfinds.com

UGC portfolio for The Well Loved Finds (Ali & Justin, South Florida). Static site served by GitHub Pages from the `main` branch.

- `index.html`, `styles.css`, `script.js`: the page, its styles (The Well Loved Finds design system) and the filter / video / copy-email script.
- `assets/`: web videos (`*-web.mp4`) and their cover images (`*-poster.jpg`), plus photos.

Updated weekly.
